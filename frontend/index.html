О конфигурации сигналаPT100/PT1000 подключаются к совместимому RTD-модулю или преобразователю; термопары требуют входного модуля соответствующего типа и компенсации холодного спая. Для RTU необходимы RS-485 и карта регистров, для TCP — Ethernet-контроллер с документированным Modbus-интерфейсом. Напрямую к компьютеру датчики не подключаются.

Настройка подключения

Масштабирование: инженерное значение = raw × коэффициент + смещение. Пример 4–20 мА = 0–100 °C: коэффициент 6.25, смещение −25, если регистр модуля содержит значение в mA. Для другого формата следуйте документации модуля.
Карта регистров температуры · адреса из документации
Выходные катушки · только для записи по карте производителя

До подтверждения разрешено только чтение. Для пуска аппаратного управления потребуется отдельное подтверждение. Адреса катушек выходов должны быть взяты из карты производителя, здесь они намеренно не заданы.

Требуемое оборудование и безопасностьRTD (PT100/PT1000): модуль RTD / преобразователь; термопара: модуль нужного типа; 0–10 В или 4–20 мА: совместимый AI-модуль/преобразователь; Modbus RTU: RS-485 + контроллер/измерительный модуль; Modbus TCP: Ethernet-контроллер. Параметры регистров берите из документации конкретного устройства. Аппаратный останов, ограничитель температуры и межблокировки должны быть реализованы независимой аппаратной цепью; ПО и связь не являются функцией безопасности.
